### 1. [What Is a Total Lunar Eclipse? — 皆既月食とは何か？](https://www.youtube.com/watch?v=nMquivqtAj0)

**入試テーマカテゴリ**: 宇宙・科学（天文現象・地球と月の関係）

**語法・関連語メモ**:
- **eclipse**: → solar eclipse（日食）/ lunar eclipse（月食）/ annular eclipse（金環食）
- **orbit**: → orbital（adj.）/ orbiter（n. 周回探査機）/ cf. rotate（自転する）

**英文サマリー**:

¶1 A total lunar eclipse occurs when the Earth passes directly between the Sun and the Moon, casting its shadow across the entire lunar surface. Unlike a solar eclipse, which is only visible from a narrow path, a total lunar eclipse can be observed from anywhere on Earth where the Moon is above the horizon.

¶2 The most striking feature of a total lunar eclipse is the reddish color the Moon takes on, earning it the nickname "blood moon." This occurs because sunlight passing through Earth's atmosphere is scattered — shorter blue wavelengths are dispersed, while longer red wavelengths are bent around the planet and reach the Moon's surface.

¶3 Scientists and educators value lunar eclipses for demonstrating key principles of light, shadow, and planetary motion. These predictable astronomical events have been used throughout history to calculate the Earth's size and to track calendar systems, making them significant not only for science but for human culture as well.

(168 words)

**日本語全訳**:

¶1 皆既月食は、地球が太陽と月の間に直接入り、月面全体に影を落とすときに起こります。特定の狭い経路からしか見えない日食とは異なり、皆既月食は月が地平線の上にある地球上のどこからでも観察できます。

¶2 皆既月食の最も印象的な特徴は、月が帯びる赤みがかった色であり、これが「ブラッドムーン（血の月）」というニックネームの由来です。これは、地球の大気を通過した太陽光が散乱するために起こります。短い青色の波長は分散され、長い赤色の波長は惑星の周りに屈折して月面に届くのです。

¶3 科学者や教育者は、光・影・惑星運動の主要原理を示す上で月食を高く評価しています。予測可能なこれらの天文現象は、歴史を通じて地球の大きさを計算したり、暦体系を追跡したりするために使われてきました。これは月食が科学だけでなく人類の文化にとっても重要であることを意味します。

**KEY SENTENCE** 🔍:

> "Shorter blue wavelengths are dispersed, while longer red wavelengths are bent around the planet and reach the Moon's surface."

[ 構文分析 ]
S: Shorter blue wavelengths / V: are dispersed（受動態）
接続: while（対比の従属接続詞）
S2: longer red wavelengths / V2: are bent（受動態）+ reach（能動態、並列）
修飾: around the planet（場所の副詞句）/ 形容詞 shorter・longer（比較の原級形容詞）

[ 入試ポイント ]
whileの対比用法（前半：青色散乱 vs 後半：赤色屈折）が入試頻出。受動態と能動態の並列構造（are bent and reach）も問われやすい。大気による光の散乱・屈折という科学的内容を平易な英文で説明する問題として、早慶・関西最難関で出題されやすい。

**確認問題 (CHECK)**:

**Q1.** [True or False] "A total lunar eclipse can only be seen from one specific location on Earth." → ( T / F )　¶1

**Q2.** [英問英答] Why does the Moon appear red during a total lunar eclipse?

**Q3.** [要約穴埋め] During a total lunar eclipse, the Moon turns red because Earth's (　①　) scatters blue light and bends (　②　) wavelengths toward the Moon.

**背景知識（教養知識）**:

[天文学的背景]
- 皆既月食は、太陽・地球・月が一直線（syzygy）に並ぶときに起こる
- 月の軌道面は地球の公転面に対して約5°傾いているため、毎月は起こらない
- レイリー散乱（Rayleigh scattering）：短波長（青）が散乱され、長波長（赤）が通過する現象で、夕焼けの赤さも同原理

[教育・入試との関連]
- 光の散乱・屈折は理科と英語の両方で重要な概念
- 「predict（予測する）」「calculate（計算する）」など科学語彙の習得に有効

**英文サマリー**:

¶1 The internet is a global network of interconnected computers and devices that communicate using a shared set of rules called protocols. When you send information — whether an email, a video, or a web page request — it is broken into small chunks called data packets, each labeled with a destination address and routed independently through the network.

¶2 Central to this system are servers: powerful computers that store and deliver content. When you type a web address, a Domain Name System (DNS) server translates that human-readable name into a numeric IP address, allowing routers to direct your request to the correct server anywhere in the world within fractions of a second.

¶3 Security is a growing concern in our digital age. Encryption technologies scramble data so that only the intended recipient can read it, while firewalls and other tools protect networks from unauthorized access. As more of daily life — from banking to healthcare — moves online, understanding how the internet works has become an essential form of digital literacy.

(165 words)

**日本語全訳**:

¶1 インターネットは、プロトコルと呼ばれる共通のルール体系を使ってやり取りする、相互接続されたコンピューターやデバイスのグローバルなネットワークです。メール、動画、ウェブページのリクエストなど、情報を送信するとき、情報はデータパケットと呼ばれる小さなかたまりに分割され、それぞれが宛先アドレスを付与されてネットワーク内を個別に経路制御されます。

¶2 このシステムの中心にあるのがサーバーです。サーバーはコンテンツを保存・配信する高性能コンピューターです。ウェブアドレスを入力すると、DNS（ドメインネームシステム）サーバーが人が読みやすいその名前を数値のIPアドレスに変換し、ルーターがリクエストを世界中の適切なサーバーに一秒の何分の一かで送り届けることを可能にします。

¶3 セキュリティはデジタル時代における深刻な懸念事項です。暗号化技術はデータを解読不能にし、意図した受信者のみが読めるようにします。一方、ファイアウォールなどのツールが不正アクセスからネットワークを保護します。銀行業務から医療まで、日常生活のより多くの部分がオンラインに移行するにつれて、インターネットの仕組みを理解することはデジタルリテラシーの不可欠な要素となっています。

**KEY SENTENCE** 🔍:

> "When you type a web address, a Domain Name System (DNS) server translates that human-readable name into a numeric IP address, allowing routers to direct your request to the correct server anywhere in the world within fractions of a second."

[ 構文分析 ]
S: a Domain Name System (DNS) server / V: translates（主節）
時間節: When you type a web address（従属接続詞when）
目的語: that human-readable name → into a numeric IP address（translate A into B 構文）
分詞構文: allowing routers to direct...（付帯状況、主節の結果を表す）
修飾: within fractions of a second（時間の副詞句）

[ 入試ポイント ]
「translate A into B」と「allow O to do」の2つの構文が1文中に登場する高頻度パターン。分詞構文（allowing〜）が付帯状況または結果を示す用法も問われやすい。技術的内容を平易な動詞構造で説明する文体は早慶高で頻出。

**背景知識（教養知識）**:

[社会的背景]
